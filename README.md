# 《机器学习》章节索引

> 「鸢尾花书」系列 · 从加减乘除到机器学习 · 本仓库已按章节重新整理目录结构

## 简介

《机器学习》（可视化）是「鸢尾花书」系列的机器学习算法卷，按「回归 → 分类 → 降维 → 聚类」四大任务组织，用大量几何可视化讲清每种算法的原理、假设与局限。全书 25 章正文，每章配 Jupyter Notebook 代码。

## 目录结构

```text
Book7_Visualizations-for-Machine-Learning/
├── Chapter_XX_<章节标题>/        # 每章一个文件夹
│   ├── BookX_ChXX_…__….pdf       # 该章讲义 PDF
│   └── BookX_ChXX_Python_Codes/  # 该章配套代码（部分章节无）
├── assets/                       # 封面、海报、系列整体布局图等
├── 综述.md                        # 全书综述与学习路径说明
├── manifest.json                 # 章节清单（机器可读）
└── README_upstream.md            # 原仓库说明（购书优惠链接等）
```
